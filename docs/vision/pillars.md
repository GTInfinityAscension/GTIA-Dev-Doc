# Design pillars

GTIA is guided GregTech where **the factory is the star**. The reference feeling is Satisfactory: building and running megafactories, many processing lines, and processing and chemistry grounded in real industry.

## The pillars

- **Grind is solved with more factory, never with more clicking.**
- **Lines get longer every tier:** Steam 2–3 steps, LV/MV 4–6, HV/EV 6–10, IV+ 10+.
- **Real chemistry, no PhD required.** Recognisable industrial processes (wood distillation, lime kiln, chlor-alkali, Bayer + Hall-Héroult, Contact process, Haber-Bosch, Solvay…), with process conditions where they make sense.
- **Two routes per important molecule:** an early, expensive one and a later, efficient one.
- **By-products connect lines.** Some are optional, some are essential. Closed loops are a challenge and a signature. Waste goes to a treatment station that gives something useful back.
- **Mega machines for everything, no multiblock limit.** Upgrades come from parts (glass, coils, casings), and parallelism is explained with numbers.
- **Every quest is reachable.** A checker reads the pack's real recipes and fails the build if a quest asks for something you cannot make yet.

## What GTIA does not do

- No research tree, research points or production quotas as gates.
- No ULV era. The campaign goes Start → Steam → LV → MV → HV → …
- No "Phase" industry. The Phase Matrix is only an ore that eases the Pulsating Alloy route.
- KubeJS is only used to remove or block recipes. Content lives in Java mods.
- Aesthetics never count toward progress.
