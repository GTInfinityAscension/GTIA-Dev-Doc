# GTIA Dev Docs

Developer documentation for **GregTech Infinity Ascension** (GTIA), a GregTech modpack for Minecraft 1.20.1 built on GTCEu Modern, the GregTech Nexus Addon (GTNA) and GTIACore.

This site is for people who build the pack: what it is trying to be, how decisions are made, and how to write code for it. Players should start at the [modpack repository](https://github.com/GTInfinityAscension/GregTech-Infinity-Ascension).

| Section | What you find there |
| --- | --- |
| [Vision](vision/pillars.md) | The design pillars, what each tier is about, and the rules for each game system |
| [Governance](governance/decisions.md) | Approved decisions and how releases work |
| [Development](development/setup.md) | Building the mods, code conventions and GameTests |

## Repositories

| Repository | Role |
| --- | --- |
| [GregTech-Infinity-Ascension](https://github.com/GTInfinityAscension/GregTech-Infinity-Ascension) | The modpack: configs, KubeJS, quests, manifest |
| [GTIACore](https://github.com/GTInfinityAscension/GTIACore) | Core mod: pack machines, chemistry slices, GTIA Rules |
| [GregTech-Nexus-Addon](https://github.com/GTInfinityAscension/GregTech-Nexus-Addon) | GTNA: large machines, Nexus energy network, endgame multiblocks |
| [Agronomica](https://github.com/GTInfinityAscension/Agronomica) | Crop breeding mod (early development) |

Policies that apply everywhere live in the organisation's [.github repository](https://github.com/GTInfinityAscension/.github): Code of Conduct, AI policy and contribution guidelines.
